# Ejercicio Threading

Este proyecto es un ejercicio realizado en Python para practicar el uso de hilos (threads).

## Descripción

El programa crea un hilo que ejecuta una función encargada de imprimir el mensaje "Hello" cinco veces.

Entre cada mensaje existe una pausa de un segundo.

Cuando el hilo termina su ejecución, el programa muestra el mensaje "finalizado".

## Tecnologías utilizadas

- Python
- Threading
- Visual Studio Code
- Git
- GitHub
